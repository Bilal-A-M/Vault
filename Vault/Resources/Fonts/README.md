# Sora (money typeface)

Download **Sora** from Google Fonts (free, SIL Open Font License):
https://fonts.google.com/specimen/Sora

Copy `Sora-Medium.ttf` and `Sora-SemiBold.ttf` from the download's `static`
folder into this folder, then run `xcodegen generate` again. Until then, money
falls back to SF Pro Rounded automatically.
